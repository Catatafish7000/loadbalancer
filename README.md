Вот моя реализация балансировщика нагрузки с циклическим перебором бекэндов (алгоритм round-robin), 
который реализован в функции GetNextBackend() в balancer.go. Все ошибки обёрнуты в JSON (errors.go), потокобезопасность
обеспечена мьютексами. Логирую через библиотеку log. Конфигурация хранится в yaml файле.

Token Bucket реализован в пакете ratelimiter в соответствии с заданием. Также реализован Graceful Shutdown и
проверка здоровья бэкэндов. Персистентность обеспечена хранением инфы о токенах в файле в формате json. Данные сохраняются
каждую минуту, файл при работе создаётся в директории data.

Для сборки проекта достаточно ввести команду docker-compose up --build -d
